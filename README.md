# 🌌 Stellar Explorer — Interactive Space Visualization

An immersive, NASA-style interactive visualization of our Solar System and the Alpha Centauri star system.

**Live Demo:** [solarsystem.aryanbansal.com](https://solarsystem.aryanbansal.com)

## ✨ Features

### 🌞 Solar System
- **8 Planets + Pluto** with realistic textures and orbital animations
- **Clickable Sun** with detailed facts and history
- **Moon exploration** for planets with natural satellites
- **Asteroid Belt** between Mars and Jupiter
- **Kuiper Belt** beyond Neptune
- **Famous Asteroids Explorer** (Ceres, Vesta, Bennu, Psyche, and more)

### ⭐ Alpha Centauri System
- **3 Stars**: Alpha Centauri A, B, and Proxima Centauri
- **Proxima Centauri b** - the closest known exoplanet
- Detailed facts and history for each star

### 🚀 Warp Transition Effect
- Cinematic shuttle launch animation
- Realistic warp speed effect with star streaks
- Distance countdown indicator
- Warp speed display (WARP 1.0 → 9.9)

### 🎮 Interactive Controls
- **Pan & Zoom** with momentum physics
- **Touch support** for mobile devices
- **Keyboard navigation** (Arrow keys, Escape)

## 🛠️ Tech Stack

- Pure HTML5, CSS3, and Vanilla JavaScript
- No frameworks or dependencies
- CSS animations and gradients for visual effects
- Responsive design

## 🚀 Deployment

### Railway
This project is configured for Railway deployment. Simply connect your GitHub repo to Railway and it will auto-deploy.

### Local Development
```bash
# Clone the repository
git clone https://github.com/bansalaryan2909-blip/solar-system.git

# Open in browser
open index.html
# or use a local server
npx serve .
```
